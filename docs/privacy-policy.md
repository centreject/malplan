## 1. 요약

- malplan은 일정과 할 일을 **사용자의 PC**에 저장합니다. 운영자는 서버를 두지 않으며, 사용자의 일정이나 계정 정보를 받거나 보관하지 않습니다.
- 사용자가 직접 켠 기능(Google Drive 동기화, 외부 AI API, 공휴일 API)을 쓸 때만, 그 기능에 필요한 데이터가 해당 서비스로 전송됩니다.

## 2. 이 PC에 저장하는 정보

| 정보 | 위치 |
|---|---|
| 일정, 할 일, 분류, 설정 | 사용자가 고른 동기화 폴더(기본: 앱 데이터 폴더)와 앱 저장소 |
| 분류 교정 기록(최대 100개) | 앱 저장소 |
| AI API 키, Google 로그인 유지 토큰 | Windows 자격 증명 관리자 |
| 공휴일 API 키(입력한 경우) | 앱 저장소 |
| 로컬 AI 모델 파일 | 앱 데이터 폴더 |

이 정보는 앱을 삭제하거나 설정에서 지우면 사라집니다. 동기화 폴더의 파일은 사용자가 직접 지울 수 있습니다.

## 3. Google 계정 연결 (선택)

사용자가 "Google로 로그인해 Drive 연결"을 누른 경우에만 동작합니다.

- **요청 권한:** `https://www.googleapis.com/auth/drive.appdata` 하나. Google Drive 안의 malplan 전용 숨김 공간(appDataFolder)만 읽고 씁니다. Drive의 다른 파일, 이메일, 연락처, 프로필 정보에는 접근하지 않습니다.
- **저장하는 것:** 일정 동기화 파일(기기별 변경 기록, 스냅샷)을 사용자 본인의 Drive 전용 공간에 둡니다.
- **전송 경로:** 사용자의 PC와 Google 사이에서만 오갑니다. 운영자에게는 전송되지 않습니다.
- **연결 해제:** 설정의 "Google Drive 연결 해제"를 누르면 Google에서 권한을 철회하고 PC의 토큰을 지웁니다. Google 계정의 [타사 앱 연결 관리](https://myaccount.google.com/connections)에서도 철회할 수 있습니다. Drive 전용 공간의 데이터는 Google 계정 설정의 Drive "앱 관리"에서 지울 수 있습니다.
- malplan이 Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)(제한적 사용 요건 포함)을 따릅니다.

## 4. 외부로 전송하는 경우 (모두 사용자가 켠 경우에만)

| 기능 | 전송하는 것 | 받는 곳 |
|---|---|---|
| AI 변환: 로컬(기본) | 없음(이 PC 안에서 처리) | — |
| AI 변환: Claude, Gemini, OpenRouter, 직접 입력한 서버 | 입력한 일정 문장, 분류 이름, 교정 예시, 사용자의 API 키 | 사용자가 고른 AI 서비스 |
| Google Drive 동기화 | 일정 동기화 파일 | 사용자 본인의 Google Drive |
| 공휴일 보완 | 연도와 월, 사용자의 공공데이터포털 API 키 | 한국천문연구원 특일정보 API(공공데이터포털) |
| 업데이트 확인 | 버전 정보 조회 요청 | GitHub(malplan 릴리스) |
| 로컬 AI 모델 받기 | 다운로드 요청 | Hugging Face |

외부 AI 서비스와 Google의 데이터 처리는 각 서비스의 개인정보처리방침을 따릅니다.
